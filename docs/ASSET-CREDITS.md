# Assets

- Original logo and palette reference: supplied by the project owner.
- public/brand/mark.svg and mark-light.svg: editable hand-redrawn approximation of the supplied monogram. They are not an original designer-supplied vector master. Replace with the official SVG when available.
- Olive, Namaa, Mizan and Forma: original HTML/CSS/SVG demo concepts created for this project. Screenshots are in database/seeders/assets. They are not real client case studies.
- Flower demo video: Mozilla MDN sample, downloaded from https://developer.mozilla.org/shared-assets/videos/flower.mp4. Used only to exercise video playback, labelled as such. Documentation: https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video
- Fonts are bundled locally via Fontsource (IBM Plex Sans Arabic, DM Sans, Cormorant Garamond), with package licenses in node_modules.
